# silver-adskip-1-mini-beta

三模态广告识别模型。给视频、音频或图片中的任意一个（或组合），分别输出「疑似广告」的概率。

**这是第一款，mini 规格，beta 状态。** 具体含义见 `DISCLAIMER.md` 第二节。

## 输入

| 模态 | 形状 | 预处理 |
|---|---|---|
| 图片 | `[1,3,32,32]` float32 | canvas 缩放到 32×32，RGB，除以 255，CHW |
| 视频 | `[8,3,32,32]` float32 | 片段时间窗内均匀抽 8 帧，各缩 32×32，同上 |
| 音频 | `[1,1,64,32]` float32 | 16 kHz 单声道 → 512 点汉宁窗 hop 256 → 功率谱 → 64 维 mel → `log(m+1e-6)` → `(m+11)/11` 截到 [0,1] → 取 32 帧 |

另有三个 mask 输入 `mask_img` / `mask_vid` / `mask_aud`，形状 `[1,1]`，给该模态就传 1.0，没给就传 0.0。输出乘过 mask，因此没给的模态输出恒为 0，直接忽略即可。

## 输出

`p_img` / `p_vid` / `p_aud`，各 `[1,1]`，值域 0–1。

## 三个文件

| 文件 | 体积 | 说明 |
|---|---|---|
| `model.fp32.onnx` | 195 KB | 原始版本 |
| `model.int8.onnx` | 168 KB | int8 动态量化（全连接层） |
| `model.q8.onnx` | 83 KB | int8 QDQ 全量化 |

三个都在 onnxruntime-web 1.17.1（WASM 后端，非 SIMD 版）实测通过：加载 10–20 ms，单次推理 <1 ms，输出与 float32 版本一致（fp32 偏差 <1e-6，int8 <1e-5，q8 <2e-3）。

## 指标（测试集，如实列出）

| 模态 | 测试准确率 | 测试 AUC | 验证准确率 | 验证 AUC |
|---|---|---|---|---|
| img | 1.000 | 1.000 | 1.000 | 1.000 |
| vid | 1.000 | 1.000 | 1.000 | 1.000 |
| aud | 0.652 | 0.820 | 0.996 | 1.000 |

测试集构成：同一支广告的后 27.5% 时间窗 vs 一支从未参与训练的影片（Blender Peach trailer）。**不是真正意义上的跨源验证**，因为广告素材只有两支。

## 已知短板

- 训练素材只有 2 支真实广告（49.7 秒）与 5 支开放影片（约 150 秒），画面多样性低
- 图片分支的样本全部来自视频帧，纯静态海报类广告没有覆盖
- 音频分支在跨源测试集上准确率 0.65、AUC 0.82，其中正样本平均 0.97、负样本平均 0.54，误报集中在「音乐/配乐密集」的非广告音轨
- 视频/图片分支在同源测试集上接近满分，这个数字说明不了真实场景表现
- 分辨率增强是「向下重采样再回 32×32」，与真实 360P 编码损失不完全等价

## 许可与使用

AGPL-3.0。可以用于个人与非商业研究。**不建议**接入任何有实际后果的流程（自动屏蔽、对外声明、申诉举证）。
