# silver-adskip-1-mini-omega

三模态广告识别模型的第三款，也是当前前端展示的那一款。状态：正式 1.0.0。相对 Alpha 的主要改动不在结构，而在**数据**：训练集第一次用上了真实剧集的片头，并且切分方式改成按源划分。

> 前端是否显示本模型，由 `models/index.json` 中本条目的 `frontend` 字段决定（当前为 `true`）。设为 `false` 即只留在仓库里，前端不出现。

## 相对 Alpha 的改动

| 项 | alpha | omega |
|---|---|---|
| 音频切分 | ad0 前 70% 训练，ad1 整支测试 | ad0 前 78% 训练，ad1 整支测试（同） |
| 负样本源 | 11 个 | **31 个**（新增电视异常画面 6 + 作者自有视频 14） |
| 切分方式 | 部分源按时间切片 | **整条源只进一个集合**，杜绝同源不同段落跨集合 |
| 损失权重 | aud 2.0 / vid 0.5 / img 0.5 | aud 2.2 / vid 0.6 / img 0.4 |
| 负样本权重 | 1.8（当时负样本偏少） | 1.5（负样本已充足，仍偏向抑制误报） |

## 新增的负样本

**电视异常画面（6 段，各 10 秒）**：SMPTE 彩条 + 1kHz、满屏雪花噪点 + 白噪、NO SIGNAL 蓝底、橙黑流动渐变、高饱和快闪、SIGNAL LOST 错误页。这些是真实的放送形态——节目结束、信号中断、测试图卡。

**作者自有视频（14 条，各取前 20 秒）**：鬼畜、快切、配音密集的短片与预告。这批是最有价值的负样本，因为它们的画面与音频形态离广告最近，也正是旧模型误判最集中的地方。

## 同一测试集上的对比

测试集来自 `ds_v5`，全部为训练中未出现过的源。

| 模态 | 版本 | 准确率 | AUC | 正均值 | 负均值 | 误报率(≥0.85) |
|---|---|---|---|---|---|---|
| 音频 | alpha v2 | 0.849 | 0.917 | 0.957 | 0.326 | 25.3% |
| 音频 | **omega** | **0.879** | **0.962** | 0.817 | **0.069** | **4.0%** |
| 视频 | alpha v2 | 0.981 | 1.000 | 1.000 | 0.047 | 2.5% |
| 视频 | **omega** | **0.994** | **1.000** | 0.985 | **0.000** | **0.0%** |
| 图片 | alpha v2 | 0.986 | 1.000 | 1.000 | 0.043 | 2.0% |
| 图片 | **omega** | **0.998** | **1.000** | 0.983 | **0.001** | **0.0%** |

音频误报率从 25.3% 降到 4.0%，代价是正样本均值从 0.957 降到 0.817——也就是更保守，漏一点，不误跳。

## 阈值建议

跨源测试集上的取舍：

| 阈值 | 广告窗口召回 | 正片窗口误报 |
|---|---|---|
| 0.60 | 81.2% | 5.93% |
| 0.70 | 78.3% | 5.14% |
| **0.80** | **74.7%** | **3.95%** |
| 0.85 | 72.0% | 3.95% |
| 0.95 | 56.8% | 2.77% |

推荐 0.80。以上是**窗口级**指标；实际一支广告持续几十秒、会产生几十个窗口，只要有一两个窗口过阈值就会跳，所以整支广告的检出率远高于窗口召回。

## 输入输出

| 模态 | 形状 | 预处理 |
|---|---|---|
| 图片 | `[1,3,32,32]` | canvas 缩 32×32，RGB/255，CHW |
| 视频 | `[8,3,32,32]` | 片段内均匀抽 8 帧，同上 |
| 音频 | `[1,1,64,32]` | 16kHz 单声道，512 点汉宁窗 hop 256， 64 维 mel，log(m+1e-6) 后 `(m+11)/11` 截 0–1，取 32 帧 |

三个输出各自独立：`p_img` / `p_vid` / `p_aud`，缺哪路输入就把对应 mask 置 0，其余照常输出。

## 判定口径

三路都给时：音频 ≥0.95 单独触发；否则要求音频越阈值且画面 ≥0.35；没有音频才回退只看画面。

加画面佐证的原因：音频分支在音效密集的正片上偶发高分（本版最高 0.995），但那些片段的画面分是 0.000，一道佐证就能挡住。

## 局限

- 广告样本仍然只有两支，其中一支整支用于测试，训练信号很薄。
- 测试集负样本源 5 个，样本量 253，统计噪声不小。
- 模型是本系列第三款，参数 70,483，仍然只做「疑似广告」的概率输出，不做跳转决策。
- 训练素材含作者自有视频，仅用于训练，未随仓库分发。

## 文件

| 档位 | 大小 | 说明 |
|---|---|---|
| fp32 | 279 KB | 原始精度，推荐 |
| int8 | 247 KB | 动态量化（全连接层） |
| q8 | 87 KB | 权重 int8 per-channel + 激活 fp32 |

三档与 numpy 参考实现的偏差分别为 1.8e-07 / 1.8e-03 / 6.6e-03，均在可用范围。
