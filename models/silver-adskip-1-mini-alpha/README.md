# silver-adskip-1-mini-alpha

三模态广告识别。**音频主判**：有音频时以音频概率为准，画面作为辅证。给什么判什么，三路概率分别输出。

第一款模型（beta）的纠正版。beta 原样保留，两个可对照选择。

## 相对 beta 的三处改动

| 项 | beta | alpha |
|---|---|---|
| 图像增强 | 含高斯模糊 σ 0–2.2 | **去掉模糊**（真实广告画面清晰，模糊会把「糊」写成判据） |
| 音频分支 | 16 / 32 / 48，FC 48 | **24 / 48 / 64，FC 64**（加宽） |
| 损失权重 | 三路等权 | **aud 2.0，vid 0.5，img 0.5**；35% 批次只喂音频 |

参数从 48,963 增至 70,483。

## 音频按源严格切分（关键）

两段广告的配乐不同、但旁白文案接近，正好可以做真正的跨源验证：

- **训练音频**：只用 ad0（23.6 秒）+ 正片音频（一段动画音轨、两段音乐）
- **测试音频**：ad1 整支（26 秒）完全留出，模型从未听过这段配乐

| 模态 | alpha（严格跨源） | 说明 |
|---|---|---|
| 音频 准确率 / AUC | **0.780 / 0.839** | ad1 完全未参与训练 |
| 音频 正样本均值 | 0.954 | |
| 音频 负样本均值 | 0.447 | 误报主要来自音效密集的 trailer 音轨 |
| 图片 准确率 / AUC | 1.000 / 1.000 | |
| 视频 准确率 / AUC | 0.992 / 1.000 | |

beta 在同一批测试样本上是 0.866 / AUC 0.915，看着更高，但它的训练集包含 ad1 的前 60%——等于考前见过题。**两个数字不可比**，参考意义在读法上：严格留出时 0.839 是本模型能拿出的真实泛化水平。

## 输入输出

| 模态 | 形状 | 预处理 |
|---|---|---|
| 图片 | `[1,3,32,32]` | canvas 缩 32×32，RGB/255，CHW |
| 视频 | `[8,3,32,32]` | 片段内均匀抽 8 帧，同上 |
| 音频 | `[1,1,64,32]` | 16 kHz 单声道 → 512 点汉宁窗 / hop 256 → 功率谱 → 64 维 mel → `log(m+1e-6)` → `(m+11)/11` 截 [0,1] → 32 帧 |

mask 输入 `mask_img` / `mask_vid` / `mask_aud`，给了传 1.0、没给传 0.0，输出已乘 mask。

## 三个文件

| 文件 | 体积 | 说明 |
|---|---|---|
| `fp32/model.onnx` | 279 KB | 原始 |
| `int8/model.onnx` | 247 KB | int8 动态量化（全连接层） |
| `q8/model.onnx` | 87 KB | 权重 int8 per-channel，激活 fp32 |

三档均通过 onnxruntime-web 1.17.1（WASM，非 SIMD）实测：加载 10–20 ms、推理 <1 ms，输出与 fp32 一致（正样本 1.000/1.000/0.996，负样本 0.003/0.0001/0）。

说明：全量化（QDQ，激活也量化）在 WASM 后端会让音频分支输出饱和在 0.498，因此 q8 采用「权重 int8 + 激活 fp32」，体积仍压到 87 KB 且数值稳定。

## 短板

- 音频 AUC 0.839，负样本均值 0.447 仍偏高：音效密集的 trailer 类音轨会被误判
- 正片音频只有三支来源
- 测试集非严格跨源（只有 2 支广告素材，拿不出未见过的广告）
- 图片分支样本全部来自视频帧
- alpha 与 beta 同为实验版
