# silver-adskip-1-Pro

广告识别 Pro，版本 1.0.0-pro.3。以 Omega 的权重为初始化，加入 18 段合成广告口播音频正样本后，**完整训练 150 轮**（实际在第 80 轮早停），参数量不变（70,483）。

这一版在跨源测试集上超过了 Omega：音频 AUC 0.9695 对 0.9622，配对 bootstrap 差 +0.0072，95% 置信区间 [+0.0011, +0.0141]，P(优于 Omega)=0.990。误报率也从 4.0% 降到 2.4%。0.5 阈值下的准确率略低（0.8712 对 0.8792），因为模型整体更保守。

前端默认仍是 Omega，本模型 `frontend=false`，需要在模型配置里手动指定 id 才会使用。

## 音频正样本怎么来的

1. 用必剪匿名 ASR 接口把两段已有广告视频的音轨转成文本，共 16 句；逐句比对 `transcript` 与 `words` 字级标签，16/16 一致。
2. 按网址、品牌、游戏名、卖点话术、行动号召归类。经作者确认，校正麻将胡了二 → 麻将胡了2、赏金女王寻宝黄金城招财喵 → 赏金女王、寻宝黄金城、招财喵，并在品牌与网址之间补停顿空格。
3. 把文案里的网址抽成变量，用 6 位随机数字加 `.com` 生成 18 个域名，替换进 18 段文本。
4. 用 Edge TTS 六种音色各合成三段音频，语速各有微调，得到 10–13 秒的 18 段音频。
5. 每段取中段 1 个窗口，做增益/噪声增强，其中约六成混入真实素材的环境声。追加 18 个音频正样本窗口，测试集与 Omega 完全一致。

## 指标（同一测试集，全部为未见过的源）

测试集音频 276 个窗口，正 102 / 负 174。

| 项 | Omega | Pro pro.3 |
|---|---|---|
| 音频 AUC | 0.9622 | **0.9695** |
| 音频准确率 @0.5 | **0.8792** | 0.8712 |
| 正样本均值 | **0.817** | 0.796 |
| 负样本均值 | 0.069 | **0.052** |
| 误报率 @0.85 | 4.0% | **2.4%** |

配对 bootstrap（2000 次重采样）：AUC 差 +0.0072，95%CI [+0.0011, +0.0141]，P(Pro>Omega)=0.990。

图像与视频分支：图像准确率 1.000 / AUC 1.000，视频准确率 0.998 / AUC 1.000。

## 阈值建议

| 阈值 | 广告窗口召回 | 正片窗口误报 |
|---|---|---|
| 0.55 | 79.6% | 3.2% |
| **0.60** | **78.3%** | **3.2%** |
| 0.65 | 77.4% | 3.2% |
| 0.70 | 76.4% | 2.8% |
| 0.75 | 75.0% | 2.4% |
| 0.80 | 73.1% | 2.4% |
| 0.85 | 68.8% | 2.4% |

建议 0.60：召回 78.3%、误报 3.2%，两项都优于 Omega 在 0.80 的 74.7% / 4.0%。索引里的 `threshold` 也是这个值。前端默认阈值是 0.80，手动切到本模型时记得一并调整。

## 输入输出

| 模态 | 形状 | 预处理 |
|---|---|---|
| 图片 | `[1,3,32,32]` | canvas 缩 32×32，RGB/255，CHW |
| 视频 | `[8,3,32,32]` | 片段内均匀抽 8 帧，同上 |
| 音频 | `[1,1,64,32]` | 16kHz 单声道，512 点汉宁窗 hop 256，64 维 mel，log(m+1e-6) 后 `(m+11)/11` 截 0–1，取 32 帧 |

三个输出各自独立：`p_img` / `p_vid` / `p_aud`。

## 文件

| 档位 | 大小 | 说明 |
|---|---|---|
| fp32 | 279 KB | 原始 float32 |
| int8 | 247 KB | int8 动态量化（Gemm） |
| fp16 | 143 KB | fp16 权重存储，运算前 Cast 回 fp32 |

这一版没有提供 q8 档：int8 权重量化在 0.60 阈值附近带来 0.03–0.04 的概率偏差，足以翻转判定。fp16 档把权重减半、Cast 回 fp32 运算，偏差只有 9.86e-04，是更安全的小体积选择。三档与 numpy 参考实现的最大偏差分别为 1.19e-07 / 8.23e-04 / 9.86e-04。

## 局限

- 广告样本仍然只有两支真实视频，其中一支整支用于测试；18 段合成音只是补充，不替代真实素材。
- 模型更保守，0.5 阈值下准确率略低；若追求更高的召回，把阈值降到 0.55。
- 合成音频的音色与背景仍与真实广告的录音条件不同。
- 训练脚本、转写文本与合成音频只留在本地，不随仓库分发；仓库只发布权重与文档。
- 输出是概率，不是结论。是否跳过由调用方按阈值与画面佐证决定。
