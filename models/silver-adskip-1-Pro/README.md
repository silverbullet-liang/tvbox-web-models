# silver-adskip-1-Pro

以 `silver-adskip-1-mini-omega` 的权重为起点，追加 6 段合成广告口播音频正样本后微调得到的版本。模型结构与参数量不变（70,483）。

先说结论：**它不是 Omega 的替代品。** 跨源测试集上，Pro 的音频 AUC 是 0.9588，Omega 是 0.9622；配对 bootstrap 的 95% 置信区间为 [-0.0065, -0.0006]，差距虽小但方向确定。0.5 阈值下 Pro 的准确率略高，但在前端默认 0.80 阈值下误报从 4.0% 升到 5.9%。因此前端默认仍是 Omega，Pro 只在仓库里提供。

## 音频正样本怎么来的

1. 用必剪匿名 ASR 接口把两段已有广告视频的音轨转成文本，各得 8 句，共 16 句。
2. 按网址、品牌、游戏名、卖点话术、行动号召归类，并校正转写里的专名与断词错误。
3. 把文案里的网址抽成变量，用 6 位随机数字加 `.com` 生成 6 个不同域名，替换进 6 段文本。
4. 用 Edge TTS 的六种音色分别合成音频（晓晓、云希、云健、晓伊、云扬、云哲），语速各有微调，得到 7–12 秒的 6 段音频。
5. 每段取 4 个均匀窗口，每窗做一次增强；其中约六成按真实素材的环境声做低电平混合，避免合成音过于干净。最终追加 48 个音频正样本窗口，全部进训练集，测试集保持与 Omega 完全一致。

训练从 Omega 的 `best.pkl` 继承权重，优化器重新初始化，学习率 3e-5 → 3e-4 余弦，27 轮早停。

## 指标（同一测试集，全部为未见过的源）

测试集音频 276 个窗口，正 102 / 负 174。

| 项 | Omega | Pro |
|---|---|---|
| 音频准确率 @0.5 | 0.879 | **0.889** |
| 音频 AUC | **0.962** | 0.959 |
| 正样本均值 | 0.817 | **0.837** |
| 负样本均值 | **0.069** | 0.082 |
| 误报率 @0.85 | **4.0%** | 5.5% |

图像与视频分支基本不变：图像准确率 0.998 / AUC 1.000，视频准确率 0.996 / AUC 1.000。

## 阈值取舍

| 阈值 | 广告窗口召回 | 正片窗口误报 |
|---|---|---|
| 0.70 | 81.0% | 6.3% |
| 0.75 | 78.8% | 5.9% |
| 0.80 | 76.9% | 5.9% |
| **0.85** | **73.9%** | **5.5%** |
| 0.90 | 70.9% | 4.3% |
| 0.95 | 62.8% | 3.6% |

建议 0.85。索引里的 `threshold` 也是这个值；如果直接套用前端默认的 0.80，误报会再高一点。

## 输入输出

| 模态 | 形状 | 预处理 |
|---|---|---|
| 图片 | `[1,3,32,32]` | canvas 缩 32×32，RGB/255，CHW |
| 视频 | `[8,3,32,32]` | 片段内均匀抽 8 帧，同上 |
| 音频 | `[1,1,64,32]` | 16kHz 单声道，512 点汉宁窗 hop 256，64 维 mel，log(m+1e-6) 后 `(m+11)/11` 截 0–1，取 32 帧 |

三个输出各自独立：`p_img` / `p_vid` / `p_aud`。

## 文件

| 档位 | 大小 | 说明 |
|---|---|---|
| fp32 | 279 KB | 原始精度 |
| int8 | 247 KB | int8 动态量化（Gemm） |
| q8 | 87 KB | 权重 int8 per-channel（QInt8） |

三档与 numpy 参考实现的最大偏差分别为 1.19e-07 / 1.01e-03 / 4.79e-03。

## 局限

- 合成音频只有 6 段，音色干净、背景简单，与真实广告的录音条件仍有差距；扩充带来的增益不足以抵消域差异。
- 跨源指标没有超过 Omega，不建议替换当前前端默认模型。
- 广告样本仍然只有两支，其中一支整支用于测试。
- 训练脚本、转写文本与合成音频只留在本地，不随仓库分发；仓库只发布权重与文档。
- 输出是概率，不是结论。是否跳过由调用方按阈值与画面佐证决定。
