# silver-adskip-1-Pro

以 `silver-adskip-1-mini-omega` 的权重为起点，追加 18 段合成广告口播音频正样本后微调得到的版本（1.0.0-pro.2）。模型结构与参数量不变（70,483）。

先说结论：**它仍不是 Omega 的替代品。** 跨源测试集上，Pro 的音频 AUC 是 0.9580，Omega 是 0.9622；配对 bootstrap 的 95% 置信区间为 [-0.0080, -0.0008]。但这一版在上一版基础上把误报率从 5.5% 压到了 4.7%，0.5 阈值准确率也高于 Omega。前端默认仍是 Omega，Pro 只在仓库里提供。

## 音频正样本怎么来的

1. 用必剪匿名 ASR 接口把两段已有广告视频的音轨转成文本，各 8 句，共 16 句；逐句比对 `transcript` 与 `words` 字级标签，16/16 一致。
2. 按网址、品牌、游戏名、卖点话术、行动号召归类。经作者确认后校正三处：麻将胡了二 → 麻将胡了2；赏金女王寻宝黄金城招财喵 → 赏金女王、寻宝黄金城、招财喵；品牌与网址之间补停顿空格。
3. 把文案里的网址抽成变量，用 6 位随机数字加 `.com` 生成 18 个不同域名，替换进 18 段文本。
4. 用 Edge TTS 的六种音色各合成三段音频（晓晓、云希、云健、晓伊、云扬、云哲），语速各有微调，得到 10–13 秒的 18 段音频。
5. 每段取中段 1 个窗口，做增益/噪声增强，其中约六成混入真实素材的环境声。最终追加 18 个音频正样本窗口，全部进训练集，测试集保持与 Omega 完全一致。

训练从 Omega 的 `best.pkl` 继承权重，优化器重新初始化，学习率 3e-5 → 3e-4 余弦，38 轮早停。

## 指标（同一测试集，全部为未见过的源）

测试集音频 276 个窗口，正 102 / 负 174。

| 项 | Omega | Pro（18 段） | Pro（上一版 6 段） |
|---|---|---|---|
| 音频准确率 @0.5 | 0.879 | **0.887** | 0.889 |
| 音频 AUC | **0.962** | 0.958 | 0.959 |
| 正样本均值 | 0.817 | 0.828 | **0.837** |
| 负样本均值 | **0.069** | 0.088 | 0.082 |
| 误报率 @0.85 | **4.0%** | 4.7% | 5.5% |

图像与视频分支基本不变：图像准确率 0.998 / AUC 1.000，视频准确率 0.996 / AUC 1.000。

## 阈值取舍

| 阈值 | 广告窗口召回 | 正片窗口误报 |
|---|---|---|
| 0.70 | 78.8% | 5.9% |
| 0.75 | 75.8% | 5.9% |
| 0.80 | 73.9% | 5.9% |
| **0.85** | **71.5%** | **4.7%** |
| 0.90 | 66.0% | 4.3% |
| 0.95 | 55.7% | 3.6% |

建议 0.85。索引里的 `threshold` 也是这个值。

## 输入输出

| 模态 | 形状 | 预处理 |
|---|---|---|
| 图片 | `[1,3,32,32]` | canvas 缩 32×32，RGB/255，CHW |
| 视频 | `[8,3,32,32]` | 片段内均匀抽 8 帧，同上 |
| 音频 | `[1,1,64,32]` | 16kHz 单声道，512 点汉宁窗 hop 256，64 维 mel，log(m+1e-6) 后 `(m+11)/11` 截 0–1，取 32 帧 |

三个输出各自独立：`p_img` / `p_vid` / `p_aud`。

## 局限

- 合成音频扩到 18 段后误报下降，但跨源 AUC 仍未超过 Omega，不建议替换当前前端默认模型。
- 合成音的音色与背景仍与真实广告的录音条件不同，域差异是主要限制。
- 广告样本仍然只有两支，其中一支整支用于测试。
- 训练脚本、转写文本与合成音频只留在本地，不随仓库分发；仓库只发布权重与文档。
- 输出是概率，不是结论。是否跳过由调用方按阈值与画面佐证决定。
