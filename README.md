# tvbox-web-models

浏览器端可直接运行的小模型集合。所有模型以 ONNX 格式发布，用 onnxruntime-web（WASM 后端）在页面内推理，不上传任何数据。

## 模型列表

| ID | 任务 | 参数 | 体积 | 状态 |
|---|---|---|---|---|
| `silver-adskip-1-mini-beta` | 三模态广告识别（视频 / 音频 / 图片） | 48,963 | 83–195 KB | beta |

索引文件：`models/index.json`。前端按其中的 `files[].url` 与 `sha256` 下载并校验。

## 目标

跑通「浏览器内、本地、不上传」的推理链路，并给出一个可参照的基线。不是生产级检测能力。

## 许可

AGPL-3.0。模型权重与推理代码同许可。

## 免责

各模型自带 `DISCLAIMER.md`，使用前必须阅读。概要：模型输出是概率估计，不是事实判定；beta 阶段可能随时变更或停止分发；不得用于作出对他人不利的决定。
